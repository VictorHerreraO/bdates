# Project Overview

**bdates** (Cumpleaños) is a weekend project Android app to track birthdays locally. It is currently pivoting to be 100% local-only (removing Firebase functions and remote data sources).

## Tech Stack
- Language: Kotlin 1.6.21
- UI: Jetpack Compose
- DI: Hilt
- DB: Room (SQLite with KTX)
- Async: Coroutines
- Architecture: Clean Architecture (Domain, Data, Framework layers), Modular.
