# Bdates Typography Guide

This document defines the typographic scale and usage rules for the Bdates brand. It ensures consistency across all screens and themes.

## 1. Typeface Selection
The Bdates brand utilizes the **System Default** fonts (Roboto on Android) to ensure maximum performance and system-level harmony.

## 2. Typographic Scale (Material 3)

| Style              | Purpose                                     | Weight   | Size |
| :----------------- | :------------------------------------------ | :------- | :--- |
| **Headline Large** | Section Headers (e.g., "Upcoming big days") | Bold     | 32sp |
| **Title Large**    | Event Name Focus                            | SemiBold | 22sp |
| **Title Medium**   | List Item Titles                            | SemiBold | 16sp |
| **Body Large**     | Primary Page Content                        | Regular  | 16sp |
| **Body Medium**    | List Item Subtitles / Dates                 | Regular  | 14sp |
| **Label Large**    | Buttons / Primary Actions                   | Medium   | 14sp |
| **Label Small**    | Secondary Tags / Overlines                  | Medium   | 11sp |

## 3. Usage Guidelines

### Display & Headlines
- Use **Headline Large** sparingly for screen-level sectioning.
- **Title Large** is reserved for high-impact content like "Today's Occasions" labels.

### Event List Typography
- **Event Name**: Must use **Title Medium**.
- **Event Date/Details**: Must use **Body Medium**.
- **Counter Labels**: Use **Label Small** (All Caps) for secondary units like "DAYS" or "YEARS".

### Form & Input Typography
- **Field Labels**: Icon + **Title Medium** (SemiBold).
- **Input Text**: **Body Large** (Regular).
- **Action Buttons**: **Label Large** (Medium, All Caps).

### Color Context
- Primary text should use the **On Surface** color.
- Secondary/Sub-text should use **On Surface Variant** (approx. 60-70% opacity equivalent).

---

## 4. Accessibility Rules
- **Minimum Contrast**: Maintain 4.5:1.
- **Scaling**: All text must use `sp` units to respect system-wide font size preferences.
- **Weight**: Avoid using weights below `Normal (400)` for critical readability.
