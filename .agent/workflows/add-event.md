# Add Event Workflow

Follow these steps to add a new event to the `bdates` app.

## Steps to Add an Event

1. **Tap on the Add Event button**: Usually represented by a `+` icon.
2. **Add an Event Name**: Enter the name of the person or event.
3. **Select Day and Month**: Use the calendar picker (optional).
4. **Provide Year**: This is optional. You may check "Don't add a year" if you wish.
5. **Finalize**: Scroll up to reveal the **"Create event"** button and tap it.

## Verification Steps

Once the event is created, verify it on the main screen:

1. **Look for the event**: Confirm it appears in the list.
2. **Check the search bar**: If the event is missing, ensure the search bar is empty.
3. **Check the carousel**: If the search bar is empty and the event isn't in the list, check the current events carousel at the top.

> [!IMPORTANT]
> If the event is still not found after these steps, verify the code and database persistence.

## Tips for Interaction

- **Soft Keyboard**: The keyboard might hide UI elements (like the "Create event" button). Hide the keyboard after finishing text input to see the full UI.
- **Scrolling**: Perform scroll gestures at the center of the item you want to scroll.
- **Clicking**: Tap events should be made at the center of the element's rectangle. Use coordinates to determine the center point if necessary.
